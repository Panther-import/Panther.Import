# Panther Import · Instagram con Claude

Este repo trae 14 skills de Instagram para Claude, copiadas de
[postzen-dev/instagram-agent-skill](https://github.com/postzen-dev/instagram-agent-skill)
(licencia en `LICENSE-instagram-skills`).

- `.claude/skills/`: las skills (`/ig-reel`, `/ig-caption`, `/ig-plan`, `/ig-publish`, etc.)
- `.mcp.json`: conexión con PostZen para publicar en Instagram
- `templates/voice.md`: completa esta ficha para que Claude escriba con tu voz

Abre una sesión de Claude Code con este repo y escribe por ejemplo `/ig-reel`.
Nada se publica sin tu aprobación.
